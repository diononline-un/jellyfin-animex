Bibliothek

Eigener Ordner, getrennt von allen bestehenden Bibliotheken. In diesen Ordner werden nur Verweis- und Metadatendateien geschrieben, kein Videomaterial.
Vorgabe {serverAddress} überlässt Jellyfin das Einsetzen der Adresse, unter der der jeweilige Client den Server erreicht.
Beim ersten Durchlauf empfohlen. Danach abschalten, damit die Bibliothek entsteht.
Ohne diese Option werden solche Einträge nur im Bericht genannt.
